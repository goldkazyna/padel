Сравнение:
V1 — Compact Cards · аккуратные карточки, незанятые в 2 колонки → меньше скролла. Клик = выбор группы (всплывают кнопки внутри карточки)
V2 — Inline Rows · одна пара = одна строка с кнопками A/B/C справа, всегда видными. 1 клик = присвоено, минимум действий. Группы справа — компактные списки без кнопок.
V3 — Pills/Chips · максимальная плотность, всё видно сразу. Чип циклит: каждый клик = переключение в следующую группу. Самое лаконичное.

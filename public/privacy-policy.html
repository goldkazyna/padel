Политика конфиденциальности

Мобильное приложение Padel KZ

Дата последнего обновления: 21 февраля 2026 г.

Настоящая Политика конфиденциальности описывает, каким образом мобильное приложение «Padel KZ» (далее — «Приложение»), разработанное Дудниковым Денисом (далее — «Оператор», «мы»), осуществляет сбор, использование и защиту персональных данных пользователей (далее — «Пользователь», «вы»).

Используя Приложение, вы соглашаетесь с условиями настоящей Политики. Если вы не согласны с её положениями, пожалуйста, прекратите использование Приложения.

1. Какие данные мы собираем

При использовании Приложения мы можем собирать следующие данные:

  • Данные учётной записи Telegram: имя пользователя, идентификатор Telegram (Telegram ID), имя и фамилия, аватар, номер телефона — при авторизации через Telegram.
  • Фотография профиля: изображение, которое вы загружаете в качестве аватара в Приложении, используя камеру или галерею устройства.
  • Идентификатор устройства (FCM-токен): уникальный токен Firebase Cloud Messaging для отправки push-уведомлений на ваше устройство.
  • Техническая информация: тип устройства, версия операционной системы, версия приложения — для обеспечения корректной работы и устранения ошибок.

2. Цели сбора данных

Мы используем ваши данные исключительно для следующих целей:

  • Авторизация и идентификация пользователя в Приложении.
  • Отображение профиля пользователя (имя, фотография).
  • Связь с пользователем при необходимости (по номеру телефона).
  • Отправка push-уведомлений о турнирах, событиях и обновлениях.
  • Обеспечение функциональности Приложения и улучшение качества сервиса.
  • Техническая поддержка пользователей.

3. Доступ к функциям устройства

Приложение может запрашивать доступ к следующим функциям вашего устройства:

  • Камера: для создания фотографии профиля. Доступ запрашивается только при выборе функции «Сделать фото» и используется исключительно для загрузки аватара.
  • Галерея / Фотоплёнка: для выбора существующего изображения в качестве фотографии профиля.
  • Push-уведомления: для получения уведомлений о турнирах и событиях. Вы можете отключить уведомления в настройках устройства в любое время.

4. Хранение и защита данных

Мы принимаем разумные технические и организационные меры для защиты ваших персональных данных от несанкционированного доступа, изменения, раскрытия или уничтожения.

Данные хранятся на защищённых серверах, расположенных на территории Республики Казахстан. Доступ к данным имеют только уполномоченные сотрудники Оператора.

Срок хранения персональных данных — в течение всего периода использования вами Приложения. При удалении учётной записи ваши данные удаляются в течение 30 дней.

5. Передача данных третьим лицам

Мы не продаём, не передаём и не раскрываем ваши персональные данные третьим лицам, за исключением следующих случаев:

  • Firebase (Google LLC): используется для отправки push-уведомлений. Передаётся только FCM-токен устройства. Политика конфиденциальности Firebase.
  • Telegram: авторизация осуществляется через Telegram Login Widget. Мы получаем публичные данные вашего профиля и номер телефона. Политика конфиденциальности Telegram.
  • По требованию закона: мы можем раскрыть данные, если это требуется действующим законодательством Республики Казахстан.

6. Права пользователя

Вы имеете право:

  • Получить информацию о хранящихся персональных данных.
  • Потребовать исправления неточных данных.
  • Потребовать удаления ваших персональных данных.
  • Отозвать согласие на обработку персональных данных.
  • Отключить push-уведомления в настройках устройства.

Для реализации своих прав свяжитесь с нами по указанным ниже контактным данным.

7. Использование файлов cookie

Мобильное приложение не использует файлы cookie. Веб-версия сервиса может использовать cookie для обеспечения корректной работы авторизации.

8. Дети

Приложение не предназначено для лиц младше 16 лет. Мы сознательно не собираем данные детей. Если вам стало известно, что ребёнок предоставил нам свои данные, пожалуйста, свяжитесь с нами для их удаления.

9. Изменения в Политике

Мы оставляем за собой право вносить изменения в настоящую Политику конфиденциальности. Актуальная версия всегда доступна по адресу: padel-p.kz/privacy-policy.

Продолжение использования Приложения после внесения изменений означает ваше согласие с обновлённой Политикой.

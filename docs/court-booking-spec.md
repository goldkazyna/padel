# Модуль бронирования кортов — ТЗ

## Принципы разработки
- Поэтапная реализация с проверкой каждого этапа
- Не ломать существующий функционал
- Оплата — заглушка (готовим структуру, но без интеграции)
- Повторяющиеся брони — отложено на будущее

---

## 1. База данных

### Таблица `courts` (корты)
| Поле | Тип | Описание |
|------|-----|----------|
| id | bigint PK | |
| club_id | FK → clubs | Привязка к клубу |
| name | string | Название корта (Корт 1, Корт 2...) |
| description | text nullable | Описание (покрытие, особенности) |
| is_active | boolean default true | Активен ли корт |
| sort_order | int default 0 | Порядок отображения |
| timestamps | | |

### Таблица `court_slots` (слоты)
| Поле | Тип | Описание |
|------|-----|----------|
| id | bigint PK | |
| court_id | FK → courts | |
| date | date | Дата слота |
| start_time | time | Время начала |
| end_time | time | Время конца |
| price | decimal(10,2) | Цена |
| status | enum: available, blocked | Статус слота |
| timestamps | | |

**Уникальный индекс:** `(court_id, date, start_time)` — один слот на корт/дату/время.

### Таблица `court_bookings` (брони)
| Поле | Тип | Описание |
|------|-----|----------|
| id | bigint PK | |
| court_slot_id | FK → court_slots | |
| user_id | FK → users | Кто забронировал |
| status | enum: confirmed, cancelled | Статус брони |
| payment_status | enum: not_required, pending, paid | Заглушка для будущей оплаты (default: not_required) |
| cancelled_at | timestamp nullable | Когда отменена |
| cancel_reason | string nullable | Причина отмены |
| timestamps | | |

### Настройки клуба (добавить в `clubs`)
| Поле | Тип | Описание |
|------|-----|----------|
| booking_cancel_hours | int default 2 | За сколько часов до слота можно отменить бронь |

## 2. Управление кортами (Club Admin)

- Список кортов клуба с toggle активности
- Создание корта (название, описание)
- Редактирование корта
- Удаление корта (soft — деактивация, если есть будущие брони)

**Контроллер:** `Club\CourtController`
**Views:** `club/courts/index`, `club/courts/create`, `club/courts/edit`

---

## 3. Управление слотами

### 3.1 Создание одиночного слота
- Выбор корта, даты, времени начала/конца, цены
- Проверка пересечений с существующими слотами

### 3.2 Генератор слотов (массовое создание)
- Период: дата начала — дата конца
- Дни недели (чекбоксы)
- Интервал слотов (30/60/90/120 мин)
- Время работы: с — до
- Цена (единая или разная для будней/выходных)
- Preview перед созданием
- Проверка пересечений

### 3.3 Управление
- Изменение статуса: available ↔ blocked
- Удаление слота — только если нет активной брони
- Массовые действия (выделить несколько → удалить/заблокировать)

**Контроллер:** `Club\CourtSlotController`

---

## 4. Экран расписания (Schedule View)

- Таблица: колонки = дни недели, строки = временные слоты
- Если кортов > 1: табы или dropdown для переключения корта
- Навигация: ← предыдущая неделя / следующая неделя →
- Цветовая индикация:
  - Зелёный — available (свободен)
  - Красный — забронирован (confirmed)
  - Серый — blocked
- Клик по слоту → быстрые действия (блокировка, просмотр брони, удаление)

**View:** `club/courts/schedule`

---

## 5. Mobile API

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/courts` | Список кортов клуба |
| GET | `/courts/{id}/slots` | Слоты корта (фильтр по дате/неделе) |
| POST | `/courts/slots/{id}/book` | Забронировать слот |
| POST | `/courts/bookings/{id}/cancel` | Отменить бронь (проверка cancel_hours) |
| GET | `/courts/my-bookings` | Мои брони |

**Контроллер:** `MobileCourtController`

Как показать статус оплаты тренера

Слева — «оплачен», справа — «не оплачен». Зелёный = оплачен, янтарный = не оплачен.

Вариант 1 — цветная сумма тренера + иконка

Сумма «+ 32 000 ₸» окрашивается: зелёная с ✓ (оплачен) / янтарная с ⏳ (не оплачен). Минимум места.
Оплачен
Безналичный
InDrive +7 775 888 81 17
64 000 ₸
Ggiorgi+ 32 000 ₸
Не оплачен
Безналичный

64 000 ₸
Ggiorgi+ 32 000 ₸

Маленькая цветная плашка-подпись рядом с суммой тренера. Самый понятный текстом.

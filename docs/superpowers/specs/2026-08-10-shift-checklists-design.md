# Чек-листы смены для менеджеров — дизайн

**Дата:** 10 августа 2026
**Область:** менеджер клуба проходит чек-лист при открытии и закрытии смены; админ задаёт пункты и видит журнал.
**Платформа:** только веб-админка клуба. Мобильное приложение не затрагивается.

## Решения владельца

1. **Блокирующе.** Менеджер без открытой смены не попадает никуда, кроме чек-листа открытия.
2. **Галочка плюс комментарий** у каждого пункта. Фото не прикладываем.
3. **Смена персональная:** если за день работают двое, каждый проходит свои чек-листы.
4. **Закрытие по кнопке** «Закрыть смену», не по времени.

## Смысл галочки

Отметка означает «проверил», а не «всё в порядке». Открыть смену можно, только отметив **все** пункты; если что-то не так, менеджер ставит галочку и пишет замечание («сетка на корте 3 порвана»).

Альтернатива — разрешить оставлять пункты неотмеченными — превращает чек-лист в формальность: половина пунктов остаётся пустой без объяснений, и админ не понимает, проверяли их или забыли.

## Данные

### `shift_checklist_items` — шаблон клуба

| Поле | Тип | Смысл |
|---|---|---|
| `club_id` | FK clubs | |
| `type` | enum `opening` / `closing` | к какому чек-листу относится |
| `title` | string 500 | текст пункта |
| `sort_order` | unsigned smallint | порядок в списке |
| `is_active` | boolean | выключенный пункт не показывается в новых сменах |

### `shifts` — смена менеджера

| Поле | Тип | Смысл |
|---|---|---|
| `club_id` | FK clubs | |
| `user_id` | FK users | менеджер |
| `opened_at` | datetime | когда открыл |
| `closed_at` | datetime nullable | пусто — смена идёт |

Индекс `(club_id, user_id, closed_at)` — по нему ищется открытая смена на каждом запросе.

### `shift_checklist_results` — что отметили

| Поле | Тип | Смысл |
|---|---|---|
| `shift_id` | FK shifts | |
| `item_id` | FK shift_checklist_items nullable | пункт может быть удалён позже |
| `type` | enum `opening` / `closing` | |
| `title_snapshot` | string 500 | текст пункта на момент прохождения |
| `is_done` | boolean | |
| `comment` | text nullable | замечание менеджера |

`title_snapshot` обязателен: админ переформулирует пункт — старые смены должны остаться такими, какими были. Без снимка журнал за прошлый месяц начнёт показывать сегодняшние формулировки.

## Поток менеджера

```
вход в /club/*
   │
   ├─ есть открытая смена? ── да ─→ работает как обычно
   │                                    │
   │                                    └─ «Закрыть смену» → чек-лист закрытия
   │                                         → closed_at, выход из системы
   │
   └─ нет ─→ есть незакрытая смена за прошлый день?
              ├─ да ─→ сначала чек-лист закрытия той смены
              └─ нет ─→ чек-лист открытия → «Открыть смену» → создаётся shift
```

Блокировка реализуется middleware на группе маршрутов `club.*`. Исключения: сам чек-лист, выход из системы, статика.

## Кого не блокируем

- **Админа клуба и супер-админа** — они не работают в смену.
- **Клуб без пунктов** — если админ не завёл ни одного пункта открытия, менеджер работает свободно: иначе новый клуб не сможет начать работу.
- **Клуб с выключенной функцией** — раздел включается feature-флагом `shifts`, как инвентарь и тренеры.

## Экраны админа

**«Чек-листы»** (`/club/shift-checklists`) — два списка, открытие и закрытие: добавить пункт, переименовать, переставить, включить и выключить. Удаление помечает пункт неактивным, а не стирает: на него ссылаются прошлые смены.

**«Смены»** (`/club/shifts`) — журнал: менеджер, время открытия и закрытия, длительность. Сверху отдельным блоком — все замечания за период, чтобы не открывать каждую смену. Внутри смены — полный чек-лист с отметками и комментариями.

## Проверка

Feature-тесты `tests/Feature/ShiftChecklistTest.php`:

- менеджера без открытой смены редиректит на чек-лист открытия с любого маршрута клуба;
- после открытия смены пускает работать;
- админа клуба и супер-админа не редиректит никогда;
- клуб без пунктов открытия не блокирует менеджера;
- смена не открывается, если отмечены не все пункты;
- закрытие проставляет `closed_at` и разлогинивает;
- незакрытая вчерашняя смена ловится раньше открытия новой;
- изменение текста пункта не меняет историю прошлых смен;
- менеджер чужого клуба не видит чужие смены и пункты.

## Что не входит

- мобильное приложение;
- фото к пунктам;
- расписание смен и учёт рабочего времени для зарплаты;
- напоминания и уведомления админу о замечаниях.

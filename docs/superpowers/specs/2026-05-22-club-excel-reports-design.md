# Excel-отчёты клуба (Фаза 1) — дизайн

**Дата:** 2026-05-22
**Статус:** утверждён к реализации

## Цель

Добавить в админку клуба отдельную страницу «Дополнительные отчёты» с выгрузкой ~13 отчётов в формате `.xlsx`. Каждый отчёт — отдельная кнопка → отдельный файл. Фильтрация по текущему клубу и выбранному периоду. Текущая страница `/club/reports` (дашборд с графиками + CSV) не меняется, кроме добавления ссылки на новую страницу.

## Решения (согласованы с заказчиком)

- **Формат:** настоящий `.xlsx` через пакет `maatwebsite/excel`.
- **Объём:** вся Фаза 1 сразу (отчёты, для которых данные уже есть).
- **Размещение:** отдельная страница `/club/reports/extra`, кнопка ведёт с `/club/reports`.
- **Файлы:** один `.xlsx` на отчёт (отдельная кнопка).
- **Зарплата тренеров:** расчёт «на лету» — проведённые брони × ставка, без новых таблиц.

## Что НЕ входит (Фаза 2 — требует новых таблиц/модулей)

Абонементы (продления/истечения, реализация+остатки), товары (продажи/остатки), расходы, полноценная касса/ДДС, подарочные сертификаты, остатки услуг (складской учёт), задачи менеджеров, смены, модуль выплат зарплат с фиксацией. На странице «Доп. отчёты» эти пункты можно показать неактивными с пометкой «скоро» (опционально), чтобы зафиксировать roadmap.

## Архитектура

Данные отделены от формата — упрощает добавление отчётов в Фазе 2 и делает расчёты тестируемыми.

### Компоненты

1. **Трейт `App\Support\ResolvesReportPeriod`**
   Выносит `parsePeriod(Request): [Carbon $from, Carbon $to, string $label]` (логика идентична `ReportsController::parsePeriod`: пресеты `today|week|month|prev_month` + custom `from`/`to`, дефолт — последние 30 дней). Подключается в новом контроллере. Старый `ReportsController` можно позже перевести на трейт, но в рамках этой задачи не трогаем.

2. **DTO `App\Reports\ReportSheet`** (простой value-object / ассоциативный массив)
   Поля: `title` (string, заголовок отчёта + период), `headings` (string[]), `rows` (array of array — значения строк), `totals` (array|null — строка итогов, выравнивается по колонкам), `columnFormats` (array<int,string>|null — формат Excel по индексу колонки, напр. `'#,##0'`, `'0%'`, `'dd.mm.yyyy'`).

3. **Сервисы-построители** в `App\Reports\` — каждый метод возвращает `ReportSheet`. Все принимают `(Club $club, Carbon $from, Carbon $to)`.
   - `ClubLoadReportService`: `byHours`, `byWeekdays`, `byMonths`
   - `ClientsReportService`: `visits`
   - `CoachesReportService`: `usage`, `sessions`, `salary`
   - `FinanceReportService`: `sales`, `byDays`, `byWeeks`, `byMonths`, `debts`
   - `ManagersReportService`: `sales`

4. **Экспорт `App\Exports\GenericSheetExport`** (на базе `maatwebsite/excel`)
   Реализует `FromArray`, `WithHeadings`, `WithTitle`, `WithStyles`, `WithColumnFormatting`, `ShouldAutoSize`. Конструктор принимает `ReportSheet`. Стили: жирная шапка с заливкой, строка итогов жирным, формат чисел/дат из `columnFormats`. Один класс на все отчёты.

5. **Контроллер `App\Http\Controllers\Club\AdditionalReportsController`**
   - `index(Request)` → страница со списком отчётов (использует `getClub()`, тот же приватный метод-паттерн, что в остальных Club-контроллерах).
   - `download(Request, string $report)` → резолвит `$report` в `(сервис, метод, имя файла)`, строит `ReportSheet`, возвращает `Excel::download(new GenericSheetExport($sheet), $filename)`.
   - Неизвестный `$report` → `abort(404)`. Нет клуба → `abort(403)`.

### Маршруты (`routes/web.php`, в группе `role:club_admin,super_admin`)

```
GET /club/reports/extra                  club.reports.extra.index
GET /club/reports/extra/{report}         club.reports.extra.download
```
`{report}` ∈ `club-hours, club-weekdays, club-months, clients-visits, coaches-usage, coaches-sessions, coaches-salary, finance-sales, finance-days, finance-weeks, finance-months, finance-debts, managers-sales`. Параметры периода — query string (`preset` или `from`/`to`).

### UI

- На `/club/reports/index.blade.php` — кнопка/ссылка «Дополнительные отчёты» → `/club/reports/extra`.
- Новая view `resources/views/club/reports/extra.blade.php`: вверху выбор периода (пресеты + custom, как на дашборде), ниже — секции по категориям (Клуб, Клиенты, Тренеры, Финансы, Менеджеры), в каждой — кнопки-ссылки на `download` с пробросом текущего периода в query string. Стиль — как существующие страницы (тёмная тема, существующие классы).

## Состав отчётов и колонки (Фаза 1)

Везде учитываем только `status = 'confirmed'` (кроме отчёта задолженностей — тоже confirmed, но `is_paid = false`). «Сумма» = `price - discount`. Все брони фильтруются по `court_id ∈ кортам клуба`.

### Клуб — загруженность
Доступные слот-часы = по активным кортам клуба: для каждого корта `(close_time − open_time)` часов × число дней периода, минус заблокированное время (`court_blocks`). Занятые часы = сумма длительностей confirmed-броней `(end_time − start_time)`.

1. **club-hours** «Загруженность по часам». Колонки: Час (08:00, 09:00 …), Занято часов, Доступно часов, Загрузка % . По каждому часу суток в диапазоне работы кортов.
2. **club-weekdays** «Загруженность по дням недели». Колонки: День недели (Пн…Вс), Занято часов, Доступно часов, Загрузка %, Кол-во броней.
3. **club-months** «Загруженность по месяцам». Колонки: Месяц (MM.YYYY), Занято часов, Доступно часов, Загрузка %, Кол-во броней.

### Клиенты
4. **clients-visits** «Посещения клиентов». Источник — `club_clients`, матчинг по телефону к confirmed-броням (учесть варианты телефона с/без ведущей 7, как `ClientController`). Колонки: Клиент, Телефон, Визитов, Сумма, Последний визит. Сортировка по числу визитов убыв. Итоги: суммарно визитов и сумма.

### Тренеры
Тренер = `court_bookings.coach_id` (FK на users), профиль/ставка — `club_coaches` (по `user_id` + `club_id`), ставки по длительности — `coach_rates`.

5. **coaches-usage** «Использование услуг». Сводка по тренерам. Колонки: Тренер, Кол-во занятий, Часов всего, Доход клуба (сумма по броням). Итоги.
6. **coaches-sessions** «Проведённые тренировки». Детальный реестр. Колонки: Дата, Время, Корт, Тренер, Клиент, Длительность (ч), Тип брони, Сумма.
7. **coaches-salary** «Зарплата тренеров». По каждому тренеру: сумма по проведённым броням `длительность(ч) × ставка`. Ставка: из `coach_rates` по длительности (`hours`), иначе `club_coaches.hourly_rate × часы`. Колонки: Тренер, Занятий, Часов, К начислению. Итоги.

### Финансы
8. **finance-sales** «Продажи». Реестр confirmed-броней. Колонки: Дата, Время, Корт, Клиент, Телефон, Сумма, Скидка, Способ оплаты, Оплачено (Да/Нет), Менеджер (booked_by). Итоги: сумма, скидка.
9. **finance-days** «Продажи по дням». Колонки: Дата, Кол-во броней, Сумма, Средний чек. Итоги.
10. **finance-weeks** «Продажи по неделям». Колонки: Неделя (период дат), Кол-во броней, Сумма, Средний чек. Итоги.
11. **finance-months** «Продажи по месяцам». Колонки: Месяц (MM.YYYY), Кол-во броней, Сумма, Средний чек. Итоги.
12. **finance-debts** «Задолженности». confirmed + `is_paid = false`. Колонки: Дата, Корт, Клиент, Телефон, Сумма, Менеджер. Итоги: общая задолженность.

### Менеджеры
13. **managers-sales** «Аналитика продаж менеджеров». Группировка по `booked_by` и дате (день = «смена»). Колонки: Менеджер, Дата, Кол-во броней, Сумма, Оплачено. Плюс по каждому менеджеру подытог за период (= «за месяц»). Итоги общие.

## Зависимость и деплой

- Локально: `composer require maatwebsite/excel`.
- `vendor` в `.gitignore` → на проде нужен `composer install`/`require`.
- **Риск:** на проде ранее падал composer (конфликт `ext-redis 5.3.7` ↔ `symfony/cache`). Установку на проде делать с учётом этого (например `composer require maatwebsite/excel --ignore-platform-req=ext-redis`, либо предварительно разрешить конфликт). PhpSpreadsheet требует расширений `ext-zip`, `ext-xml`, `ext-gd`/`ext-mbstring` — проверить наличие на проде до выкладки.

## Тестирование

- Unit-тесты на сервисы-построители (PHPUnit): на фикстурах броней проверяем корректность расчётов — загрузка %, сумма продаж, агрегации по дням/неделям/месяцам, расчёт зарплаты по `coach_rates`/`hourly_rate`, матчинг клиента по вариантам телефона.
- Smoke-тест контроллера: каждый `{report}` отдаёт HTTP 200 и `content-type` xlsx; неизвестный отчёт → 404; чужой клуб не виден.
- Ручная проверка: открыть выгруженные файлы в Excel, кириллица и числа/даты корректны.

# Раздел «Тренировки» — дизайн

**Дата:** 9 августа 2026
**Область:** тренер создаёт и ведёт тренировки, игроки записываются, всем приходят напоминания.
**Репозитории:** `C:\projects\padel` (Laravel API), `C:\projects\padel_app` (Flutter).
**Платформа:** только мобильное приложение. Веб-экранов не делаем, API живёт на бэкенде.

## Решения владельца

1. **Корт не выбирается.** Тренер указывает клуб и время; корт бронирует отдельно, своим порядком. Тренировка не занимает слот в расписании кортов и не конфликтует с бронями.
2. **Лимит участников задаёт тренер.** Когда мест нет, кнопка записи гаснет.
3. **Оплата не учитывается.** Цена показывается игроку при записи, деньги тренер берёт на месте.
4. **Игрок видит все ближайшие тренировки** одним списком по дате, без фильтров. Клуб виден на карточке.

Плюс решение, принятое при проектировании: **клуб выбирается из всех клубов, кроме комьюнити**, а не только из тех, где тренер числится в `club_coaches`. Так тренер может провести занятие где угодно.

## Данные

### `trainings`

| Поле | Тип | Смысл |
|---|---|---|
| `coach_id` | FK users | кто проводит |
| `club_id` | FK clubs | где проводит |
| `starts_at` | datetime | начало; хранится как настенное время Алматы, как `tournaments.start_date` |
| `duration_minutes` | unsigned smallint | длительность, 30–300 |
| `price` | unsigned integer | цена в тенге, 0 = бесплатно |
| `capacity` | unsigned tinyint | максимум участников, 1–32 |
| `description` | text nullable | необязательное описание |
| `status` | enum | `planned` / `completed` / `cancelled` |

Индекс по `starts_at` — список игрока сортируется по нему.

### `training_participants`

| Поле | Тип | Смысл |
|---|---|---|
| `training_id` | FK trainings | |
| `user_id` | FK users | |
| `reminded_1d_at` | datetime nullable | отметки об отправленных напоминаниях, |
| `reminded_2h_at` | datetime nullable | чтобы пуш не ушёл дважды — |
| `reminded_1h_at` | datetime nullable | тот же приём, что у участников турнира |

Уникальный ключ `(training_id, user_id)` — защита от двойной записи при повторном тапе.

Запись игрока — это строка. Тренер удаляет участника — строка удаляется: история записей не нужна, а список всегда показывает актуальный состав.

### Модели

`Training` (`coach()`, `club()`, `participants()`, `isPast()`, `hasFreeSlots()`), `TrainingParticipant`. Логика статусов — в `TrainingService`, чтобы контроллеры остались тонкими.

## Переходы статусов

```
planned ──► completed   (тренер, только когда время окончания прошло)
   │
   └──────► cancelled   (тренер, в любой момент)
```

Завершённую и отменённую тренировку менять нельзя, записаться в них тоже нельзя. Время окончания = `starts_at + duration_minutes`.

## API

Все маршруты — в группе `auth:sanctum` файла `routes/api.php`, префикс `/api/mobile`.

### Тренер (роль `coach`)

| Метод | Путь | Что делает |
|---|---|---|
| GET | `/coach/trainings` | свои тренировки, ближайшие сверху; у каждой число записавшихся |
| POST | `/coach/trainings` | создать |
| GET | `/coach/trainings/{training}` | детали с участниками: имя, телефон, аватар |
| PUT | `/coach/trainings/{training}` | правка, пока `planned` |
| POST | `/coach/trainings/{training}/complete` | завершить; 422, если время ещё не вышло |
| POST | `/coach/trainings/{training}/cancel` | отменить; участникам уходит пуш |
| DELETE | `/coach/trainings/{training}/participants/{user}` | убрать участника |
| GET | `/coach/clubs` | клубы для выпадающего списка (без комьюнити) |

Чужую тренировку тренер не видит и не меняет — 403.

### Игрок

| Метод | Путь | Что делает |
|---|---|---|
| GET | `/trainings` | открытые предстоящие, по дате; тренер, клуб, цена, свободные места, флаг `is_joined` |
| GET | `/trainings/{training}` | детали |
| POST | `/trainings/{training}/join` | записаться; 422 если мест нет, тренировка прошла, отменена или уже записан |
| POST | `/trainings/{training}/leave` | отписаться |
| GET | `/trainings/my` | свои записи: предстоящие и прошедшие |
| GET | `/trainings/count` | `{"upcoming": N, "available": M}` — для бейджей |

`available` — сколько открытых предстоящих тренировок со свободными местами; это число висит на плитке главного экрана. `upcoming` — на сколько записан сам игрок; это бейдж кнопки в профиле.

## Напоминания

Команда `trainings:send-reminders` по образцу `SendTournamentReminders`: за сутки, за два часа и за час до начала. Уважает пользовательскую настройку `notify_tournament_reminders` — отдельного тумблера не заводим, пока тренировки не обжились. Пишет запись в `notifications` (`type = training_reminder`) и шлёт пуш через `FCMNotificationService`.

Регистрируется в том же планировщике, где уже крутятся напоминания о турнирах и бронях.

Отдельно: при отмене тренировки каждому записавшемуся уходит пуш `training_cancelled` с названием клуба и временем.

## Экраны приложения

**Кабинет тренера** (`coach_schedule_screen`) получает кнопку «Создать тренировку» и список своих тренировок под расписанием. Карточка тренировки открывает экран с участниками; у каждого — меню из трёх точек: позвонить, написать в WhatsApp, удалить из тренировки. Тот же набор действий, что у админа в участниках турнира. Внизу — «Завершить» (после окончания) и «Отменить» (всегда).

**Экран создания**: клуб, дата и время, длительность, цена, максимум участников, описание.

**Главная**: плитка «Создать игру» в блоке сервисов заменяется на «Тренировки» с красным бейджем — числом доступных тренировок. Создание игры остаётся доступным с экрана «Игры».

**Список для игрока**: карточки по дате, ближайшие сверху — тренер, клуб, время, длительность, цена, свободные места. Внутри — описание и кнопка «Записаться» / «Отписаться».

**Профиль**: под «Приглашения на турнир» встаёт кнопка «Мои тренировки» с бейджем предстоящих — по образцу `TournamentInvitationsButton`.

Отдельный тест на команду напоминаний: три отметки проставляются по одному разу, повторный прогон ничего не шлёт.

Flutter — `flutter analyze`; автотестов в проекте нет.

## Что сюда не входит

- веб-интерфейс тренировок;
- учёт оплаты и отметки «оплатил»;
- повторяющиеся тренировки (каждый вторник и т.п.);
- привязка к корту и создание брони;
- отдельный тумблер уведомлений о тренировках в настройках.

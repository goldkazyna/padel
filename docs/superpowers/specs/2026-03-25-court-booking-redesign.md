# Редизайн системы бронирования кортов

## Проблема

Текущая система требует ручной генерации слотов — админ должен заранее создавать временные окна, прежде чем кто-то сможет забронировать корт. Это лишний шаг: слоты должны быть всегда открыты автоматически.

## Решение: Виртуальные слоты

Слоты не хранятся в БД. Расписание вычисляется на лету из настроек корта (часы работы + шаг). В БД попадают только бронирования и блокировки.

## 2. Экраны

### Экран 1: Расписание (`/club/courts/schedule`)

Главный рабочий экран админа.

**Шапка:**
- Выбор даты (календарь + стрелки вперёд/назад по дням)
- Кнопка "Сегодня" для быстрого возврата

**Тело:**
- Таблица: строки = часы (08:00, 09:00, ..., 21:00), колонки = корты
- Каждая ячейка — один слот одного корта
- Цветовая кодировка:
  - Свободный — кликабелен → модалка бронирования
  - Забронирован (синий) — показывает имя клиента + цену, кликабелен → модалка с инфой + отмена
  - Заблокирован (серый) — кликабелен → разблокировать
- Если бронь на 2+ часов — ячейки объединяются визуально

**Модалка бронирования (клик по свободному слоту):**
- Показывает: корт, дата, время, цена за час
- Выбор количества часов (1, 2, 3... — пока свободно подряд)
- Итоговая цена (автоподсчёт)
- Поля: имя клиента, телефон (необязательно)
- Кнопка "Забронировать"

**Модалка просмотра (клик по забронированному):**
- Инфо: корт, дата, время, клиент, телефон, цена
- Кнопка "Отменить бронь"

**Блокировка:**
- Правый клик или долгий тап → заблокировать/разблокировать

### Экран 2: Настройки кортов (`/club/courts`)

**Список кортов — карточки:**
- Название, статус (активен/неактивен)
- Часы работы
- Количество ценовых интервалов
- Кнопки: редактировать, деактивировать, удалить

**Модалка создания/редактирования корта:**
- Название, описание
- Время работы: с / до
- Ценовые интервалы — динамический список:
  - Строка: время от — время до — цена
  - Кнопка "+ Добавить интервал"
  - Валидация: покрытие всего рабочего времени без пробелов и пересечений

## 3. Бизнес-логика

### Построение расписания

1. Берём настройки корта: open_time, close_time, slot_duration
2. Генерируем сетку часов: [08:00, 09:00, ..., 21:00]
3. Из БД: бронирования (confirmed) на выбранную дату
4. Из БД: блокировки на выбранную дату
5. Для каждого часа: booking → "забронирован", block → "заблокирован", иначе → "свободен"

### Бронирование

1. Админ кликает свободный слот → модалка
2. Выбирает длительность (1, 2, 3 часа — пока подряд свободно)
3. Проверка: нет бронирований/блокировок на выбранный диапазон
4. Подсчёт цены по ценовым интервалам (каждый час по своей цене)
5. Создание записи в court_bookings

### Блокировка

1. Проверка: нет бронирований на это время
2. Создание записи в court_blocks
3. Разблокировка — удаление записи

### Отмена бронирования

1. Статус → cancelled, ставится cancelled_at
2. Слот снова свободен

### Валидация ценовых интервалов

- Интервалы не пересекаются
- Покрывают всё рабочее время (open_time–close_time)
- Нет пробелов

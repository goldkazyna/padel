  • Клик по зелёному слоту — открывает модалку бронирования (попробуй кликнуть на 08:00 Корт 1)

  • Бронь на 2 часа (Марат Б. 10:00-12:00 Корт 1) — ячейки объединены
  • Заблокированные слоты (Корт 3, 08:00-09:00) — серые
  • Цены меняются по времени: утро 3000₸, день 5000₸, вечер 8000₸
  • Правый клик для блокировки — не реализован в мокапе, но будет в финальной версии

# Формат турнира «Эскалера» — веб-версия

**Дата:** 9 августа 2026
**Статус:** согласовано, готово к планированию
**Исходная спецификация формата:** `escalera-final.md` (версия 2.0, утверждённая владельцем)

## Задача

Новый тип турнира «Эскалера» — лестница из кортов, где после каждого раунда лучший на корте поднимается, худший опускается. Первый заход — полный цикл проведения в вебе: создать турнир, расставить игроков, сыграть раунды, закрыть турнир с наградами. Мобильное приложение — следующим этапом, после того как формат обкатают вживую.

## Правила формата

Корты пронумерованы сверху вниз, на каждом четыре игрока. За раунд внутри корта играются три коротких матча — каждый с каждым в паре. По их итогам четвёрка ранжируется с первого по четвёртое место.

Перемещения: первый на корте идёт вверх, четвёртый вниз, двое средних остаются. На верхнем корте вниз уходит только четвёртый, на нижнем вверх идёт только первый.

Зачёт индивидуальный: партнёр меняется каждый матч, результат зависит только от самого игрока.

### Как считается таблица

Очки, набранные внутри корта, в общую таблицу **не идут** — они нужны только чтобы упорядочить четвёрку. В таблицу попадает позиция игрока в общем строю всех участников:

```
позиция = (номер корта − 1) × 4 + место на корте
баллы   = всего игроков − позиция + 1
```

При 12 игроках первая позиция даёт 12 баллов, двенадцатая — 1. Итог турнира — сумма баллов за все раунды.

Смысл: номер корта уже встроен в число. С третьего корта нельзя получить позицию лучше девятой, даже выиграв там всё, а с первого даже полный провал даёт четвёртую. Единственный способ улучшить результат — подняться выше.

## Решения

| Вопрос | Решение |
|---|---|
| Объём первого этапа | Полный цикл проведения в вебе |
| Рейтинг | Начисляется сразу, по каждому короткому матчу, существующей формулой ELO |
| Режим ранжирования внутри корта | Оба: по очкам и по победам, выбор при создании |
| Стартовая расстановка | Автоматически по рейтингу, с ручной перестановкой до старта |
| Таймер раунда и лимит времени | Не делаем вообще |
| Жребий при полном равенстве | Не делаем: выше ставится игрок с большим рейтингом |
| Публичная ссылка на таблицу | Отложена |

### Про рейтинг

Исходная спецификация формата советовала обрабатывать турнир как единый результат по финальной таблице, а не по матчам. Владелец решил иначе: начислять по каждому короткому матчу существующей парной формулой ELO. Это его осознанное решение, принятое после того, как последствие было названо: в американо игрок проводит за турнир 7–11 матчей, в эскалере при семи раундах — 21, поэтому рейтинг за вечер будет двигаться примерно втрое сильнее.

Формула парная (2 на 2), а в эскалере пары меняются каждый матч, так что она ложится без переделок. Если после первого турнира окажется, что рейтинг скачет слишком резко, добавляется понижающий множитель — правка одной строки.

## Архитектура

### Тип турнира

Значение `escalera` добавляется в enum `tournaments.type` отдельной миграцией — так же, как это делалось для `just_padel_it` (`database/migrations/2026_07_05_000002_add_just_padel_it_to_tournaments_type_enum.php`).

Существующие поля турнира переиспользуются: `courts_count` — количество кортов, `max_participants` — число игроков. Новые параметры формата (`очков в коротком матче`, `режим ранжирования`) — отдельными колонками в `tournaments`.

### Таблицы

**`escalera_players`** — участник турнира:
`tournament_id`, `user_id`, `total_points` (сумма баллов за все раунды), `start_court`, `current_court`, `wins` (выигранных коротких матчей за турнир), `rating_before`, `rating_after`. Уникальный ключ по паре турнир-игрок.

`start_court` нужен для награды «Восхождение», `wins` — для первого тай-брейка итоговой таблицы.

**`escalera_rounds`** — раунд: `tournament_id`, `round_number`, `status` (`pending`, `in_progress`, `completed`). Уникальный ключ по паре турнир-номер.

**`escalera_round_courts`** — корт в раунде: `escalera_round_id`, `court_number`, `player1_id`…`player4_id`. Порядок игроков — это посадка, от неё строится очерёдность матчей.

**`escalera_matches`** — короткий матч: `escalera_round_court_id`, `match_number` (1–3), `team1_player1_id`, `team1_player2_id`, `team2_player1_id`, `team2_player2_id`, `team1_score`, `team2_score`, `status`.

**`escalera_round_results`** — результат игрока за раунд: `escalera_round_id`, `user_id`, `court_number`, `place_on_court` (1–4), `overall_position`, `points`. Нужна, чтобы показывать изменение позиции с прошлого раунда и историю движения по кортам.

### Сервис

`app/Services/EscaleraService.php` — вся логика формата. Контроллер только принимает запросы и отдаёт вьюхи.

```php
// Стартовая расстановка: посев по рейтингу, создание первого раунда.
public function startTournament(Tournament $tournament): bool

// Сохранить счёт короткого матча.
public function saveMatchResult(EscaleraMatch $match, int $team1Score, int $team2Score): void

// Все ли счета внесены — от этого зависит доступность закрытия раунда.
public function canCloseRound(Tournament $tournament): bool

// Превью закрытия: места на кортах и перемещения, без записи.
public function previewRoundClose(Tournament $tournament): array

// Закрыть раунд: места, позиции, баллы, перемещения, обновление таблицы.
public function closeRound(Tournament $tournament): bool

// Следующий раунд по результатам перемещений.
public function generateNextRound(Tournament $tournament): bool

// Завершить турнир: награды и начисление рейтинга.
public function finishTournament(Tournament $tournament): bool
```

### Порядок матчей на корте

От посадки игроков (1 — сильнейший по посадке, 4 — слабейший):

1. Матч 1: игроки 1+4 против 2+3 — самый ровный
2. Матч 2: игроки 1+3 против 2+4
3. Матч 3: игроки 1+2 против 3+4

Каждый играет в паре с каждым по разу.

### Ранжирование внутри корта

**По очкам** (режим по умолчанию): сумма всех очков, набранных командой игрока в трёх матчах. Больше — выше.

**По победам**: число выигранных из трёх матчей. При равенстве — по сумме очков, затем по личной встрече (сумма очков в тех двух матчах, где игроки были соперниками).

Если после всех тай-брейков сохраняется полное равенство — выше ставится игрок с большим рейтингом. Жребия нет.

### Перемещения

Первый на корте вверх, четвёртый вниз, двое средних остаются. Верхний корт: первые трое остаются, четвёртый вниз. Нижний корт: первый вверх, остальные трое остаются.

После перемещений обязательная проверка: на каждом корте ровно четыре игрока. Если не сходится — раунд не закрывается, показывается ошибка.

### Рассадка в следующем раунде

На корте оказываются четверо: пришедший снизу, пришедший сверху и двое оставшихся. Они рассаживаются по текущему положению в общей таблице — лидер занимает первую позицию, дальше по убыванию. Порядок матчей строится от этой посадки так же, как в первом раунде.

Правило детерминированное: одни и те же входные данные всегда дают одну и ту же расстановку.

## Интерфейс

### Создание турнира

Тип «Эскалера» в списке. Свои параметры:

- количество кортов — от 2 до 10;
- очков в коротком матче — 8, 10, 12 или 16, по умолчанию 12;
- режим ранжирования внутри корта — по очкам или по победам.

Число участников проставляется автоматически как корты × 4 и отдельно не редактируется — иначе значения разъедутся. Количество раундов не задаётся.

### Стартовая расстановка

Отдельная страница по образцу `resources/views/club/tournaments/justpadelit/seeding.blade.php`: игроки отсортированы по рейтингу и разложены по кортам сверху вниз, первые четверо на первый корт. Двух игроков можно поменять местами до старта. Игроки без рейтинга ставятся ниже всех.

Пока участников не ровно корты × 4, старт заблокирован и показано, сколько человек не хватает или сколько лишних.

### Экран турнира

Карточки кортов сверху вниз, верхний первым. На карточке четыре имени в порядке посадки и три матча с полями счёта.

Цвет карточки: серый — счетов нет, жёлтый — часть внесена, зелёный — все три готовы.

Счёт вводит администратор клуба. Валидация: сумма очков двух команд равна заданному числу. При двенадцати очках допустимы 7:5 и 8:4, но не 12:10.

### Закрытие раунда

Кнопка активна, только когда внесены все счета на всех кортах. Показывается превью: места на каждом корте с первого по четвёртое и стрелки перемещений. Рядом две кнопки — сгенерировать следующий раунд или завершить турнир.

### Таблица

Позиция, игрок, сумма баллов, текущий корт, изменение позиции с прошлого раунда.

Тай-брейки итоговой таблицы по порядку: сумма баллов, количество выигранных коротких матчей за турнир, личная встреча, рейтинг.

**Личная встреча** здесь — сумма очков, набранных этими игроками в тех матчах турнира, где они были соперниками. Игроки могли ни разу не пересечься, если держались на разных кортах: тогда этот тай-брейк пропускается и сравнение переходит к рейтингу.

**Изменение позиции с прошлого раунда** — это изменение места в общей таблице турнира (по сумме баллов), а не позиции в строю за раунд. В первом раунде колонка пустая.

### Финал

Итоговая таблица и три награды:

- **Чемпион** — наибольшая сумма баллов;
- **Восхождение** — наибольшая разница между стартовым и финальным кортом; при равенстве выше тот, чей финальный корт выше;
- **Король корта** — победитель финального раунда на первом корте.

### Правка счёта задним числом

Разрешена администратору. Показывается предупреждение: перемещения уже произошли, пересчитается только таблица.

## Краевые случаи

| Ситуация | Поведение |
|---|---|
| Участников не кратно четырём или не совпадает с кортами | Старт заблокирован, показано расхождение |
| Сумма очков матча не равна заданной | Счёт не сохраняется, показывается ошибка |
| После перемещений на корте не четверо | Раунд не закрывается, показывается ошибка |
| Полное равенство внутри корта | Выше игрок с большим рейтингом |
| Два корта, минимально допустимое | Работает: верхний и нижний, средних кортов нет |
| Правка счёта после закрытия раунда | Пересчитывается только таблица, перемещения остаются |

## Тестирование

Тесты на сервис:

- ранжирование внутри корта по очкам;
- ранжирование по победам, включая тай-брейк по очкам и по личной встрече;
- полное равенство решается рейтингом;
- формула позиции и баллов на разном числе игроков;
- перемещения: обычный корт, верхний, нижний;
- проверка «на каждом корте четверо» после перемещений;
- порядок трёх матчей соответствует посадке, каждый играет с каждым;
- старт заблокирован при неверном числе участников;
- сумма очков матча валидируется;
- рассадка следующего раунда детерминирована;
- награды считаются верно на подготовленных данных;
- рейтинг начисляется по каждому короткому матчу.

Прогон точечный через `--filter`: в сьюте есть давно падающие тесты, не связанные с этой работой.

## Вне рамок

- Мобильное приложение — следующий этап после обкатки в вебе.
- Таймер раунда, лимит времени и индикация просрочки.
- Публичная ссылка на таблицу и экспорт картинкой.
- Экраны игрока и пуш-уведомления о новом корте.
- Ввод счёта самими игроками и подтверждение проигравшей парой.
- Жребий кнопкой при равенстве.

# Отчёт «Неоплаченные тренеры»

**Дата:** 2026-06-26
**Страница:** `/club/reports/extra` (Доп. отчёты), категория «Тренеры»

## Задача

Дать клубу Excel-отчёт за период со списком броней, где тренеру ещё не оплачено,
чтобы понимать, кому и сколько нужно выплатить. Read-only (статус оплаты меняется
в самой брони, не в отчёте).

## Что считается «неоплаченным»

Бронь корта, у которой:
- назначен тренер (`coach_id` не null),
- `coach_paid = false`,
- `status = 'confirmed'`,
- `date` в выбранном периоде.

Групповые занятия теперь всегда сохраняются с `coach_paid = true` (см. фикс в
`CourtController`), поэтому в отчёт естественно попадают только индивидуальные /
мягкие / турнирные брони — ровно то, что нужно.

## Реализация

Полностью повторяет существующий паттерн отчётов (`app/Reports/*`):

1. **`CoachesReportService::unpaid(Club $club, Carbon $from, Carbon $to): ReportSheet`**
   - Запрос: как `coachBookings()`, но с дополнительным `->where('coach_paid', false)`.
   - Сумма тренеру за бронь = `coach_price`, если задана, иначе
     `ClubCoach::getRateForHours(floor(hours))` (то же правило, что в `incomeByType`).
   - Строка на каждую бронь, сортировка по тренеру → дате.
   - Итоговая строка с суммой к выплате.

2. **Регистрация в `AdditionalReportsController::REPORTS`:**
   ```php
   'coaches-unpaid' => [CoachesReportService::class, 'unpaid', 'trenery-neoplacheno', 'Тренеры', 'Неоплаченные тренеры'],
   ```
   Метод `download()` уже универсальный, `index()` сам сгруппирует под «Тренеры».
   Период берётся из существующего фильтра страницы (`ResolvesReportPeriod`).

## Структура листа

| Дата | Время | Корт | Тренер | Клиент | Тип | Сумма тренеру (₸) |
|------|-------|------|--------|--------|-----|-------------------|

- Сортировка: по имени тренера, затем по дате.
- Итог: `['Итого', '', '', '', '', '', <сумма>]`, формат суммы `#,##0`.
- Тип: те же лейблы, что в `sessions()` (Индивид./Мягкая/Турнир/Групповая).

## Вне области (YAGNI)

- Никаких кнопок «оплатить» в отчёте (read-only).
- Без агрегатного листа по тренерам (только детализация по броням).
- Существующие отчёты не трогаем.

## Тесты

Feature-тест на `download` маршрут отчёта `coaches-unpaid`:
- бронь с тренером и `coach_paid=false` в периоде → попадает в отчёт;
- бронь с `coach_paid=true` → не попадает;
- бронь без тренера → не попадает;
- бронь вне периода → не попадает.

# Групповые занятия — инструкция для админа клуба

Раздел «Группы» в админке клуба нужен для постоянных тренировочных групп: фиксированный состав участников, оплата пакетами занятий (абонементами), списание занятия по факту посещения.

---

## С чего начать

Откройте боковое меню клуба → **Группы** (раздел появляется, если для клуба включена фича `groups` — если пункта нет, попросите супер-админа включить).

На странице две вкладки:
- **Активные** — группы, по которым идут занятия.
- **Архивные** — группы, переведённые в архив. По ним нельзя создавать новые занятия, но история сохраняется.

---

## 1. Создание группы

1. Нажмите **«+ Создать группу»**.
2. Заполните карточку:
   - **Название** (обязательно). Пример: «Утренняя группа», «Дети 8–10 лет».
   - **Тренер** (опционально). Этот тренер будет подставляться по умолчанию при создании бронирования корта для группы.
   - **Цена за занятие** (опционально). Используется как ориентир при оформлении пакетов.
   - **Вместимость** (опционально). Максимум участников в группе.
   - **Заметка** — любая внутренняя информация (расписание словами, особенности и т.д.).
3. Сохраните. Группа создаётся со статусом **«Активная»**.

---

## 2. Участники группы

В карточке группы → блок **«Участники»**.

### Добавить участника
1. **«+ Добавить участника»**.
2. В поле поиска начните вводить **имя** или **телефон** клиента — список подтянется автоматически из карточек клиентов клуба (`club_clients`).
   - Карточка клиента — источник истины. Если клиента ещё нет в системе — сначала создайте его в разделе **Клиенты**.
3. Выберите клиента → он добавится в группу.

### Удалить участника
Кнопка корзины напротив участника. Удаление мягкое: его пакеты и история посещений сохраняются, но занятия дальше списываться не будут.

---

## 3. Пакеты занятий (абонементы)

В карточке участника есть блок **«Пакеты»** — это сколько занятий клиент оплатил.

1. **«+ Добавить пакет»**.
2. Укажите количество занятий и (опционально) сумму.
3. Сохраните.

Остаток считается как **(сумма по всем пакетам) − (число посещённых занятий, где было списание)**.

В форме бронирования и в карточке группы рядом с именем участника показывается бейдж:
- **Зелёный** — больше 2 занятий в остатке.
- **Жёлтый** — 1–2 занятия (пора предложить продлить пакет).
- **Красный** — 0 или меньше (пакет закончился).

---

## 4. Создание занятия (привязка к корту)

Занятие группы всегда привязано к бронированию корта — это даёт единый журнал и автоматическое предотвращение коллизий.

### Через расписание кортов (рекомендованный путь)
1. Откройте **Корты → Расписание**.
2. Кликните по свободному слоту нужного корта.
3. В форме брони:
   - **Тип брони** → «Групповые».
   - Появится селект **«Группа (создаст занятие в журнале)»** — выберите нужную группу.
   - Под селектом сразу подгрузится список участников и их остаток занятий.
   - Под участниками появится **«Тренер»** — по умолчанию подставится тренер группы, при необходимости поменяйте.
   - **Длительность**, **Комментарий** — заполните по необходимости.
   - Поля имени клиента, телефона, способа оплаты, цены — **не нужны** для группового занятия (оплата идёт через пакеты).
4. **«Забронировать»**.

Бронь корта создаётся, и одновременно в **«Журнал занятий»** падает запись со статусом **«Запланировано»**.

### Через раздел «Журнал занятий»
1. **Журнал занятий → «+ Создать занятие»**.
2. Выберите группу, корт, дату, время. Тренер подтянется автоматически.
3. Сохраните — создастся и бронь корта, и запись в журнале.

> **Архивная группа** не позволит создать новое занятие. Сначала верните её в активные.

---

## 5. Проведение занятия и посещаемость

1. В **«Журнал занятий»** найдите нужное занятие.
2. Откройте — увидите карточку с участниками и чекбоксами «пришёл / не пришёл».
3. **Важно:** кнопка «Провести» становится доступной **только после окончания времени занятия**. Заранее проставить нельзя — это защита от ошибочных списаний.
4. Отметьте пришедших → **«Провести»**.
5. Что происходит:
   - У отмеченных списывается одно занятие из остатка их пакета.
   - Статус занятия меняется на **«Проведено»**.
   - Списание заморожено: если переоткроете — нельзя двойного списания.

### Если что-то не сошлось
- У участника **закончился пакет** (0 в остатке) — занятие можно провести, но списания не будет, появится предупреждение. Продайте новый пакет через карточку клиента.
- **Отмена занятия**: на карточке занятия кнопка «Отменить». Если оно ещё не проведено, бронь корта тоже отменится автоматически (и наоборот — отмена брони корта снимает занятие).

---

## 6. Архив и удаление группы

В карточке группы (правый верхний угол) две кнопки:

- **Архивировать** — группа уходит в архив:
  - Все будущие занятия по ней отменяются (и снимаются соответствующие брони кортов).
  - Прошлые проведённые занятия и история остатков **сохраняются**.
  - Группу можно вернуть в активные кнопкой **«Вернуть из архива»**.

- **Удалить** — полное удаление:
  - Все занятия группы (включая прошлые), пакеты, посещаемость и связанные брони кортов будут удалены каскадом.
  - **Восстановить нельзя.** Если есть сомнения — используйте архив.

---

## 7. Частые сценарии

| Ситуация | Что делать |
|----------|-----------|
| Клиент пропустил занятие | Не отмечайте его «пришёл» — занятие не спишется. |
| Клиент оплатил наличными — продлить пакет | В карточке клиента в группе → **«+ Добавить пакет»**. |
| Перенос занятия на другое время | Отмените текущее занятие, создайте новое на нужное время (через расписание кортов). |
| Тренер заболел — нужна замена | Откройте бронь корта этого занятия, поменяйте тренера. |
| Группа больше не набирается | Архивируйте — будущие занятия отменятся, история останется. |
| Тестовая группа, нужно убрать совсем | Удалить (только если уверены — каскадно сносит всё). |

---

## 8. Что увидит игрок (в мобильном приложении)

На текущей версии (1.5.x) групповые занятия в мобильном приложении игрокам **не показываются** — это пока внутренний инструмент клуба. Игрок продолжает видеть только турниры, рейтинг, своё расписание турниров.

Push-уведомления об отмене групповых занятий — на стадии планирования.

---

## 9. Технические нюансы

- Раздел доступен только при включённой фиче `groups` для клуба (включает супер-админ).
- Списание занятий регистрируется в `club_group_attendances.charged = true` и пересчитывается каждый раз при открытии карточки участника.
- Для тренера группы **не требуется** настраивать недельный график в разделе «Тренеры» — для групповых броней проверка графика пропущена. Достаточно того, что тренер числится в клубе.
- Доступ модератора клуба — на чтение и проведение занятий; создание/удаление групп — только админ клуба.

Если что-то ведёт себя неожиданно — пришлите скрин и описание шагов в чат поддержки, разберём.

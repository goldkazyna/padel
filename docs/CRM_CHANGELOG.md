# Журнал изменений CRM (веб-панель клуба)

Живой журнал правок и новых фич веб-CRM (`/club/...`). Новые записи — сверху.
Формат записи: **дата · что сделано** — детали, `коммит`, деплой.

## 2026-07-21

### Помощь: раздел «Расписание и брони» (1 статья)
- «Расписание и брони кортов»: сетка время×корты (по кортам/по дням), создание брони (длительность, цена/скидка, тип, оплата, тренер), недельный вид, работа с бронями. Реальные скрины. Базовый набор инструкций CRM закрыт.

### Помощь: раздел «Группы и занятия» (2 статьи)

- Фильтры по колонкам: селекты Группа/Тренер/Корт/Статус (значения из данных). `коммит 8ae6a20`.
- Убраны текстовые фильтры (Дата/Время/Присут./Списано); добавлена **выгрузка в Excel** отфильтрованных строк (.xls). `коммит 759c469`.

### Список групп (`/club/groups`) — выгрузка
- Кнопка «Выгрузить в Excel»: список групп текущей вкладки (Группа/Тренер/Цена/Участников/Вместимость/Статус). `коммит b06b63b`.

### Мягкое удаление участника группы
- Удаление участника теперь мягкое: `status=inactive` + `left_at` (без физического удаления). Причина: жёсткое удаление каскадило посещаемость/пакеты и **занижало выручку** задним числом + стирало историю клиента.
- `addMember` реактивирует «бывшего», сохраняя историю. `коммит 1faa23d`.
- **Деплой миграции:** `php artisan migrate --path=database/migrations/2026_07_20_000002_add_left_at_to_club_group_members.php`

## Правила по CRM (памятка)
- Ширина страниц — **1200px** (`max-width:1200px;margin:0 auto`).
- Иконки — **только монохромные** (Bootstrap Icons), без цветных emoji.
- Пользовательские строки в admin/club-экранах — можно на русском (не требуют локализации).
- Бэкенд коммитить и пушить сразу; миграции деплоить через `--path=` к конкретному файлу.

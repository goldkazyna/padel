### Американо: правка кол-ва групп и раундов в форме редактирования турнира
- Раньше «Количество групп» в `tournaments/edit` было `disabled` («нельзя изменить после создания»). Теперь **до старта** турнира американо можно менять **кол-во групп** (1–4) и **кол-во раундов** (1–30) прямо в веб-форме. Группы редактируемы, только пока они ещё **не сформированы** (иначе рассинхрон с редактором групп — тогда поле readonly с подсказкой «сбросьте группы»). Раунды редактируемы, пока турнир не начат. Гейтинг продублирован на сервере (`Club\TournamentController@update`: `groups_count`/`rounds_count` вырезаются из запроса, если условия не выполнены). При старте раунды берутся из `rounds_count` (кап = игроков в группе − 1, `AmericanoService`). Только код, деплой без миграций.

### Защита: рейтинг игрока меняется не чаще раза в 2 месяца
- На `/club/users` после ручной смены рейтинга/уровня игрок «замораживается» на **2 месяца**: в модалке редактирования поля **Уровень** и **Рейтинг** становятся `disabled` + жёлтая плашка «Изменить уровень и рейтинг можно с ДД.ММ.ГГГГ». В списке у такого игрока рядом с кнопкой редактирования — иконка-замок с датой разблокировки. **Имя менять можно всегда.** Отсчёт — от последней записи `rating_history` с `reason='Ручная корректировка'` (+2 месяца). **Супер-админ ограничение обходит.** Защита продублирована на сервере (`Club\UserController@update` вырезает `level`/`rating` из запроса, если кулдаун активен и это не супер-админ). **То же самое сделано и в мобильном API** (`Api\MobileAdminUserController`): `index` отдаёт `rating_locked_until` по каждому игроку, `update` возвращает 422 при попытке сменить уровень в кулдаун (супер-админ — без ограничений). Только код, деплой без миграций.

## 2026-07-22

### Брони: мультитренер (спарринг с несколькими тренерами)
- Индивидуальную бронь корта можно вести с 2–5 тренерами (спарринг): у каждого своя цена и статус оплаты. В окне брони/редактирования тренеры выбираются мультивыбором — на каждого выбранного появляется строка с полем цены и чекбоксом «оплачен». Основной тренер (первый) дублируется в `court_bookings.coach_id` для совместимости (групповые брони, занятость), все тренеры хранятся в пивоте `court_booking_coaches`. Занятость тренера учитывает и пивот (нельзя занять тренера, если он уже доп. тренер в пересекающейся броне). Доп. тренеры показываются на карточке брони (по кортам и по дням). Отчёты по тренерам (зарплата, доход по типам, неоплаченные, итоги выплат) считают всех тренеров брони, а не только основного. Групповые брони — без изменений (тренер один). `коммиты 71aec31 (бэкенд) + UI/отчёты`. Деплой миграции: `php artisan migrate --path=database/migrations/2026_07_22_000003_create_court_booking_coaches_table.php`

## Правила по CRM (памятка)
- Ширина страниц — **1200px** (`max-width:1200px;margin:0 auto`).
- Иконки — **только монохромные** (Bootstrap Icons), без цветных emoji.
- Пользовательские строки в admin/club-экранах — можно на русском (не требуют локализации).
- Бэкенд коммитить и пушить сразу; миграции деплоить через `--path=` к конкретному файлу.

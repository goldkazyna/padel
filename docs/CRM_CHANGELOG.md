Формат записи: **дата · что сделано** — детали, `коммит`, деплой.

## 2026-07-23

### Журнал групп (/club/groups/journal)
- Отдельная страница-история по группам в стиле журнала действий: фильтры по группе, типу события, дате, поиск; группировка по дням; раскрытие «было→стало». Кнопка «Журнал» в тулбаре `/club/groups` и на странице каждой группы (предфильтр по ней). Логируются ВСЕ события групп с понятными статусами (Создание/Изменение/Проведено/Отмена/Продление/Заморозка/Разморозка/Возврат/Удаление): группа (создание/архив/возврат/удаление, +счётчик отменённых занятий), участник (добавлен/возвращён/абонемент изменён/продление/убран/заморозка/разморозка), занятие (создано/проведено с «присутствовали N, списано M»/отменено). **Причина отмены занятия**: при ручной отмене — модалка «Причина», сохраняется и видна в журнале; авто-отмены (архив/удаление группы, снятие брони в расписании) получают причину сами. Таблица: колонка `activity_logs.group_id` (без FK — история сохраняется после удаления группы). `коммит 171cc77`. Деплой миграции: `php artisan migrate --path=database/migrations/2026_07_23_000001_add_group_id_to_activity_logs.php`

## 2026-07-22

### Брони: мультитренер (спарринг с несколькими тренерами)
- Индивидуальную бронь корта можно вести с 2–5 тренерами (спарринг): у каждого своя цена и статус оплаты. В окне брони/редактирования тренеры выбираются мультивыбором — на каждого выбранного появляется строка с полем цены и чекбоксом «оплачен». Основной тренер (первый) дублируется в `court_bookings.coach_id` для совместимости (групповые брони, занятость), все тренеры хранятся в пивоте `court_booking_coaches`. Занятость тренера учитывает и пивот (нельзя занять тренера, если он уже доп. тренер в пересекающейся броне). Доп. тренеры показываются на карточке брони (по кортам и по дням). Отчёты по тренерам (зарплата, доход по типам, неоплаченные, итоги выплат) считают всех тренеров брони, а не только основного. Групповые брони — без изменений (тренер один). `коммиты 71aec31 (бэкенд) + UI/отчёты`. Деплой миграции: `php artisan migrate --path=database/migrations/2026_07_22_000003_create_court_booking_coaches_table.php`

### Группы: «дата начала» участника (отложенный старт)
- Необязательное поле `starts_at` у участника группы: клиент занимает место сразу, но занятия НЕ списываются до этой даты. Логика в `GroupSessionService::conduct` (charge только если `hasStartedOn`). Поле в модалках добавления/редактирования участника; бейджи «начнёт с …» на странице группы и в проведении занятия (charge заблокирован до старта, как заморозка). Колонка `club_group_members.starts_at`. Деплой миграции: `php artisan migrate --path=database/migrations/2026_07_22_000001_add_starts_at_to_club_group_members.php`

### Восстановление пароля по телефону + SMS (/forgot-password)
- Фирменная страница (тёмная тема, зелёный, логотип) на 2 шага: ввод телефона → SMS-код + новый пароль/повтор → смена и автологин. SMS через тот же `SmsService`, что и приложение (текст «Padel KZ Ваш код OTP: {code}», тестовый код 1111). Контроллер `Auth\PhonePasswordResetController` (sendCode/reset), роуты `password.phone.send`/`password.phone.reset`. Деплой: `git pull && php artisan route:clear && php artisan view:clear`.

### Редизайн страницы входа (/login)
- Стандартный Breeze-шаблон заменён на фирменную страницу: тёмная тема, зелёный акцент, логотип PADEL KZ, вкладки телефон/email, Telegram-вход. `коммит 6ec932a`. Деплой: `git pull && php artisan view:clear`. (Telegram-виджет рендерится только на боевом домене.)

## Правила по CRM (памятка)
- Ширина страниц — **1200px** (`max-width:1200px;margin:0 auto`).
- Иконки — **только монохромные** (Bootstrap Icons), без цветных emoji.
- Пользовательские строки в admin/club-экранах — можно на русском (не требуют локализации).
- Бэкенд коммитить и пушить сразу; миграции деплоить через `--path=` к конкретному файлу.

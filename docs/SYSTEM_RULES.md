# Строгие правила системы PADEL KZ

> Единый свод правил, по которым работает система. Любая доработка не должна их
> нарушать. При изменении правила — обновляй этот файл.

---

## Рейтинг

- **Формула** — Elo (`app/Traits/RatingCalculator.php`): изменение зависит от разницы
  рейтингов команд, счёта и K-фактора. Фаворит за победу получает мало, за
  ничью/поражение с более слабыми — теряет.
- **Начисляется один раз — в момент завершения турнира** (если турнир рейтинговый).
  После завершения рейтинг «заморожен».
- **⚠️ Матч со счётом 0:0 НЕ влияет на рейтинг** — он приравнивается к отменённому
  (несыгранному). Реализовано в трейте `RatingCalculator::calculateRatingChange`,
  поэтому действует для ВСЕХ форматов турниров.
- **Правка счёта после завершения не пересчитывает рейтинг автоматически.** Если
  исправили счёт у завершённого турнира — рейтинг остаётся от старых цифр. Для
  ремонта: `php artisan tournaments:recalc-flex {id} --apply` (флекс) — пересчитывает
  по текущим счётам без 0:0.
- **Ручная корректировка** рейтинга/уровня (админ/супер-админ через раздел
  «Пользователи»): пишется в `rating_history` с `tournament_id = null`,
  `reason = 'Ручная корректировка'`. В приложении показывается как
  «Ручная корректировка · Padel Kz».
- **Уровень** = `rating * 1000 + 125` (обратно: rating ≈ level×1000+125). Шаг уровня 0.25.
- **Верификация уровня (галочка)** при ручной простановке — только если у игрока
  есть аватар (фото).
- Нерейтинговые турниры (`is_rated = false`, а также все личные турниры игроков)
  рейтинг не начисляют.

## Турниры — участники и запись

- **Полнота турнира считается по `registered + pending`** (утверждённые + на
  модерации). Именно эта сумма сравнивается с `max_participants`.
- **Лимит участников соблюдается во всех точках** записи и перемещений — нельзя
  превысить `max_participants` (учитывая и pending).
- **Лист ожидания (waitlist):** при отмене/освобождении места первый из очереди
  автоматически переходит на модерацию (`waiting → pending`), с проверкой лимита.
- **Модерация (таймер):** просрочивший заявку уходит в конец листа ожидания, на его
  место подтягивается следующий (крон `tournaments:process-moderation`).

## Just Padel It (соло)

- **Посев доступен только когда игроков ровно `courts_count × 4`**
  (`Tournament::jpiSeedingReady`). Иначе кнопки «Посев» нет — ни в приложении, ни в
  вебе. Число кортов у JPI редактируется.

## Americano Flex

- **Таблица сортируется по среднему очков за матч** (`очки ÷ сыгранные матчи`) — так
  честнее из-за отдыхающих (byes), которые дают разное число матчей у пар.
- **Матч 0:0 не учитывается** в таблице (матчи/очки/В/П) и в рейтинге — как несыгранный.
- Парный флекс: строка таблицы = пара; статистика пары берётся по player1 (в паре у
  обоих одинаковая).

## Клубные карты (счётчики часов)

- **Списание часов — после окончания брони**, кроном `cards:charge-due` (или вручную
  из раздела «Списания»). Списывает только `confirmed` брони, идемпотентно
  (`card_charged_at`).
- **Доступный остаток = `balance − зарезервировано`.** Зарезервировано — сумма часов
  подтверждённых броней с этой картой, которые ещё не списаны (`card_charged_at IS NULL`).
  Будущие брони «занимают» часы, поэтому нельзя набронировать больше, чем реально
  осталось на карте. Проверяется при создании и редактировании брони; в расписании и
  выборе карты показывается именно доступный остаток (`ClubCardService::availableBalance`).
- Скидочные карты (не счётчики) остатка не имеют — часы не резервируют и не списывают.

## Клубы / комьюнити

- Клубы и комьюнити — одна модель `Club` (разделены флагом `is_community`).
- **Список сортируется:** 1) по числу проведённых (завершённых) турниров;
  2) у кого есть открытые турниры — выше; 3) «скоро открытие» (coming_soon) — в конец.

## Кто может создавать турниры

- **Клуб / комьюнити** (админ/модератор с правом на турниры) — полноценные,
  могут быть рейтинговыми, публичные.
- **Игрок с грантом `can_create_tournaments`** — только личные (приватные)
  турниры: без клуба, всегда нерейтинговые, не видны в публичной вкладке.
- Супер-админ может управлять любым клубом и ставить уровни любому игроку.

## Отмена турнира

- Организатор может отменить турнир (статус → `cancelled`) пока он `open`/`in_progress`
  — из приложения (⋮ «Остановить турнир») или из веба (смена статуса).
- При отмене и при изменении даты турнира всем записанным участникам летит пуш
  (observer модели `Tournament`).
- Удалить турнир можно только пока он в статусе `draft` (черновик).

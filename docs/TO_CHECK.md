
## Цена группы за час (15.09.2026)

- Группа → «Редактировать»: под ценой появился выбор «за занятие / за час».
  У всех старых групп стоит «за занятие» — цифры не должны были поменяться.
- «ГРУППА 10| АБОНЕМЕНТ| ЧТ-СБ» (Padel Hills) уже переведена на «за час»:
  в шапке должно быть «4 000 ₸/час».
- Расписание → тап по будущему занятию этой группы: в модалке для часового
  четверга «20 000 ₸ (4 000 ₸ × 5, 4 000 ₸/час)», для субботы 13:00–15:00 —
  «40 000 ₸ (8 000 ₸ × 5, 4 000 ₸/час)».
- Там же поменять длительность кнопками 1ч/2ч/3ч — сумма должна пересчитаться
  сразу, без закрытия модалки. Проверить в ОБОИХ видах: по кортам и по дням.
- Провести субботнее занятие → в журнале и в отчёте о доходах должно упасть
  40 000 ₸, а из абонемента у каждого списаться ОДНО занятие (не два).

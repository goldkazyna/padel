Padel KZ — платформа для управления турнирами по падел-теннису (Казахстан)

=== МОБИЛЬНОЕ ПРИЛОЖЕНИЕ (Flutter) ===

Авторизация:
- Вход по номеру телефона (SMS код)
- Привязка к Telegram (опционально)

Главная:
- Карточка игрока (имя, рейтинг, место в рейтинге)
- Ближайший/активный турнир
- Список предстоящих турниров

Турниры:
- Просмотр открытых турниров (название, дата, клуб, уровень, цена, кол-во мест)
- Запись на турнир (индивидуально или парой)
- Поиск партнёра по номеру телефона
- Отмена записи
- Мои турниры (активные и архивные с результатами)
- Детали турнира (участники, группы, сетка плей-офф, результаты матчей)

Форматы турниров:
- Classic — группы + плей-офф (нокаут)
- Americano — круговой формат, индивидуальный рейтинг
- Mexicano — ротация пар с учётом истории
- Team — командный формат (пары), группы + плей-офф

Рейтинг:
- ELO-система (база 1000, K-фактор зависит от рейтинга)
- Топ игроков с пагинацией
- Фильтр по уровню, поиск по имени
- Карточка "мои соседи" (кто рядом в рейтинге)
- Уровни игроков (1-5+) на основе рейтинга

Профиль:
- Редактирование: имя, фамилия, отчество, город, пол, возраст, рабочая рука, позиция
- Статистика: кол-во турниров, побед, поражений

Уведомления:
- Push-уведомления через Firebase (FCM)
- Типы: новый турнир, одобрение/отклонение записи, освободилось место
- Колокольчик с непрочитанными
- Настройка: получать уведомления только по своему уровню

Проверка обновлений:
- При запуске проверяет актуальность версии
- Мягкое/принудительное обновление

=== АДМИН-ПАНЕЛЬ (Laravel, веб) ===

Роли:
- super_admin — управление клубами
- club_admin — управление турнирами своего клуба
- club_moderator — проведение турниров

Функционал клуба:
- Создание/редактирование турниров (все 4 формата)
- Управление участниками (одобрение, отклонение, замена)
- Проведение турнира: жеребьёвка групп, ввод счёта, генерация плей-офф
- Форматы плей-офф: mix, group_vs, tops, cross, balanced
- Push-рассылка о новом турнире (через FCM топик — все получают моментально)
- Публикация турнира в Telegram-канал
- Просмотр списка пользователей с фильтром по уровню

=== ИНТЕГРАЦИИ ===

- Firebase Cloud Messaging — push-уведомления
- Telegram Bot API — уведомления, мини-апп
- Telegram Mini App — веб-версия внутри Telegram
- SMS — авторизация по телефону

=== СТЕК ===

Backend: Laravel 12, PHP, SQLite
Frontend (веб): Blade, Tailwind CSS, Alpine.js
Mobile: Flutter/Dart
Хостинг: VPS (padel-p.kz)
